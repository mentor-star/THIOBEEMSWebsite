# THIOBEEMS University Website

Standalone HTML/CSS/JavaScript university website for THIOBEEMS University, Cameroon.

## Pages
- Home
- About
- Programmes
- Online Admission
- Student Login
- Student Dashboard
- Admin Login
- Admin Dashboard
- Contact

## Run
Open `index.html` directly, or serve the folder using a local static web server.

## Important
Authentication, applications, uploaded documents and dashboard data are frontend demos using localStorage. For a real university, connect these interfaces to a secure backend/database, implement server-side authentication, file storage, validation, email notifications and access control.
